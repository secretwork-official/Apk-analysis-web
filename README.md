# APK Analyzer by Abhigyan

Upload an Android .apk and get a full automated security report: app metadata,
the signing certificate, every domain/URL/IP/email found inside the file,
possible leaked API keys and private keys, dangerous permissions, exported
components, a plain-language fix for each issue, and an overall security
score. Also supports comparing two versions of the same app.

No login. Files are processed in memory and discarded immediately after the
report is generated. Max file size: 150 MB.

Only analyze apps you own or are authorized to test.
